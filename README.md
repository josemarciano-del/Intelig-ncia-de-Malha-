# Inteligência de Malha — Cordenonsi

Objetivo: mapear as **rotas tronco** da operação (trechos compartilhados por várias origens/destinos)
a partir da rota planejada e do GPS realizado, para padronizar o cadastro de rotas no portal
(hoje cadastradas CNPJ → CNPJ, com muita duplicidade).

- Mapeamento das APIs e qualidade dos dados: [docs/apis.md](docs/apis.md)
- Token de acesso: variável de ambiente `CRD_TOKEN` (nunca versionar).
